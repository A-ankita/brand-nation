Add an article

How to publish changes to your GitHub website:
  1. Edit articles here and click Save Article.
  2. Click Download catalogue.json.
  3. In your GitHub repository, upload the downloaded catalogue.json to the same root folder as index.html, replacing the existing file, and commit.
  4. Wait for GitHub Pages to redeploy, then refresh the site. The updated products will appear for everyone.
Important: Saving alone updates only this browser. GitHub Pages cannot write to your repository automatically. The catalogue manager is not password protected; edits made by other visitors stay in their own browsers unless they upload a file to your GitHub repository. Keep downloaded JSON files backed up. Uploaded photos are compressed to reduce file size.
