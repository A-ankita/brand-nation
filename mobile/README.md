# Brand Nation mobile app

Native Android/iOS app starter built with Capacitor 7. The app bundles its own home screen, native Share/Haptics/Network integrations, and opens the live https://brand-nation.in website for product browsing and checkout. Website changes and catalogue sync remain independent.

## Local setup

Requirements: Node.js 22, npm, Android Studio for Android, macOS/Xcode for iOS.

```bash
cd mobile
npm install
npm run build
npx cap add android
npx cap add ios # macOS only
npx cap sync
npx cap open android # or npx cap open ios on macOS
```

Run `npm run build` after modifying `src/app.js`. The `www/app.js` file is generated by esbuild during build and should not be edited manually.

## Test builds

GitHub Actions workflow `.github/workflows/mobile-build.yml` attempts an Android **debug APK** and an **unsigned iOS simulator build**. Check the Actions run and download successful build artifacts; workflow existence does not guarantee successful builds. The iOS simulator app cannot be installed on a physical iPhone.

## Before public release

- Implement native/in-app product browsing, reliable deep links, and a better in-app checkout journey. The current home shell opens the existing store in a system browser view; it is **not** a complete native shopping experience.
- Verify Razorpay, COD, WhatsApp links, images, accessibility, and customer data handling on physical devices.
- Replace provisional bundle ID `in.brandnation.shop` if necessary and confirm ownership.
- Prepare real app icon, splash artwork, store screenshots, privacy policy and data-safety disclosures.
- Configure Android release signing for AAB and Apple Developer signing for iOS archive/TestFlight.
- Apple and Google may reject thin wrappers; add meaningful mobile-specific functionality and ensure policy compliance before submission.

No live website changes or app store publishing are performed by this branch.
