# Brand Nation — GitHub Pages Website

## Deploy
Upload `index.html`, `catalogue.json`, and the complete `assets` folder to the root of a public GitHub repository. Go to Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Edit your catalogue on the website
1. Open your published website and scroll to the footer. Click **Manage catalogue**.
2. Click Edit on a product, or use Add an article. Change the name, price, category, tag, and upload a photo. Save Article.
3. Click **Download catalogue.json**.
4. On GitHub, open the existing `catalogue.json` file and replace it with the downloaded file (or delete the old one and upload the new one). Commit the change.
5. Wait for GitHub Pages deployment and refresh the website.

**Important:** GitHub Pages is static hosting. Editing on the website changes only your current browser until you upload the exported `catalogue.json` to GitHub. There is no shared admin login or automatic saving to GitHub. Visitors may open the manager but cannot change the public site without repository write access. Photos are embedded into JSON and compressed; large catalogues may make the file large. Keep a backup of your JSON.
